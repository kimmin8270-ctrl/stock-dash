# PlanX 03회 — 산업 성장이 기업 돈으로 바뀌는 과정

> **판정: 보류**
>
> 출처기관: 관세청·금융감독원 전자공시시스템(OpenDART)  
> 조회일: 2026-09-19  
> 기준기간: 미확정(월별·분기별 원자료 미수집)  
> 단위: 수출금액 미확인 / 기업 공시 연결·별도 미확인  
> 확정 여부: 관세청·OpenDART 원본 수치 미확인

## 1. 관심 섹터

전력기기(전력용 변압기).

선정은 분석 후보일 뿐 투자 결론이 아니다. 최종 수요에서 수출·수주, 가동률, 매출 인식, 영업레버리지로 이어지는지 필수 원자료가 모두 확보된 뒤에만 판단한다.

## 2. HS 세부코드와 국가

대상국은 미국이다. HS 8504 전체 합계를 그대로 변압기 수출로 사용하지 않고 아래 6단위 소호를 우선 분리한다.

| HS 6단위 | 분류 |
|---|---|
| 850421 | 액체 유전체 변압기, 용량 650kVA 이하 |
| 850422 | 액체 유전체 변압기, 650kVA 초과 10,000kVA 이하 |
| 850423 | 액체 유전체 변압기, 10,000kVA 초과 |
| 850431 | 기타 변압기, 용량 1kVA 이하 |
| 850432 | 기타 변압기, 1kVA 초과 16kVA 이하 |
| 850433 | 기타 변압기, 16kVA 초과 500kVA 이하 |
| 850434 | 기타 변압기, 500kVA 초과 |

한국 관세청 통계에는 조회 시점의 HSK 10단위 세부코드와 코드 개정 이력을 적용해야 한다. 정류기·인버터·인덕터 등 HS 8504 내 비변압기 품목은 제외한다.

## 3. 확인 주기

- 관세청 미국향 월별 수출금액: 매월
- OpenDART 생산능력·생산실적·가동률·수주상황: 분기보고서 및 사업보고서 공시 때
- 수출 증가율과 기업 매출 증가율 교차상관: 분기 종료 후 공시가 나온 때
- 수주잔고와 매출 인식 점검: 분기

## 4. 수출→매출 예상 시차

**미확인.** 0·1·2분기 시차를 모두 계산하기 전에는 특정 시차를 채택하지 않는다.

계산 정의:

- 분기 수출액 = 해당 분기 월별 수출금액의 합
- 수출 YoY(%) = (당해 분기 수출액 / 전년 동기 분기 수출액 - 1) × 100
- 매출 YoY(%) = (당해 분기 기업 매출 / 전년 동기 기업 매출 - 1) × 100
- 교차상관 = Corr(수출 YoY_t, 기업 매출 YoY_{t+k}), k = 0, 1, 2
- 비교 전 기업별 연결/별도 기준, 통화, 단위, 분기 누적/단일분기를 일치시킨다.

## 판단 순서별 검증 상태

| 단계 | 필요한 공식 증거 | 현재 상태 |
|---|---|---|
| 최종 수요 | 미국 전력망 투자·발주 공식 자료 | 미입력 |
| 수출·수주 | 관세청 미국향 월별 HSK 수출액, OpenDART 수주상황 | 미확인 |
| 가동률 80% | 사업보고서/분기보고서 생산능력·생산실적·가동률 | 미확인 |
| 매출 인식 | 동일 기업 분기 매출과 수주 인식 시점 | 미확인 |
| 영업레버리지 | 동일 기준 매출 증가율과 영업이익 증가율 | 미확인 |

## 실제 병목 기업 판정

**판정 불가.** 가격·납기·가동률 병목을 입증할 관세청 월별 원자료와 기업별 OpenDART 원문 수치가 현재 확보되지 않았다. 기업 IR·언론의 주장만으로 병목 기업을 지정하지 않는다.

## 원자료 대조 규칙

1. 관세청 월별 원자료 합계와 분기 합계를 다시 대조한다.
2. HS 8504 전체와 변압기 소호 합계를 구분한다.
3. 기업 매출은 같은 기업·같은 회계기준·같은 단위로 비교한다.
4. 전년동기비 계산 결과를 공시 수치와 대조한다.
5. 표본이 너무 짧거나 한두 개 이상치가 상관계수를 지배하면 시차를 채택하지 않는다.
6. 상관관계는 인과관계로 표현하지 않는다.

## 마지막 판정

**보류**

필수 원자료 3종 가운데 다음이 누락되어 매수 결론을 만들 수 없다.

- 관세청 수출입무역통계: 미국향 HS 8504 월별 금액과 변압기 HSK 세부코드 재분류 결과
- OpenDART 사업보고서/분기보고서: 후보 기업별 생산능력·생산실적·가동률·수주상황
- 위 자료로 계산한 0~2분기 교차상관과 원자료 합계 대조표

## 폐기 조건

아래 중 하나 이상이면 전력기기 성장→기업 이익 전환 가설을 폐기한다.

1. 미국향 변압기 세부코드 분기 수출 YoY가 2개 분기 연속 음수이고, 같은 기간 후보 기업 수주잔고도 감소한다.
2. 가동률이 80% 미만인데도 납기 장기화 또는 가격 상승을 병목 근거로 주장할 공식 자료가 없다.
3. 0~2분기 모든 시차에서 수출 YoY와 기업 매출 YoY의 상관 방향이 일관되지 않거나 표본 확장 후 관계가 사라진다.
4. 매출 증가에도 영업이익률이 2개 분기 연속 하락하고, 일회성 비용을 제외한 공식 설명으로 반전 근거가 확인되지 않는다.

## 다음 입력 필요 항목

- 관세청 수출입무역통계에서 내려받은 미국향 HS 8504 월별 CSV/XLSX 또는 해당 API 접근키
- 분석할 기업 1~3개(예: HD현대일렉트릭, 효성중공업, 일진전기)의 확정 목록
- OpenDART API 접근키 또는 각 기업의 대상 사업보고서·분기보고서 접수번호

공식 원자료가 입력되면 동일 기준으로 재계산하여 관찰/매수/폐기 여부를 갱신한다.
